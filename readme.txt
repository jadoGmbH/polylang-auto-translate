Translates content from the original language text using MyMemory/translated.com while preserving the Gutenberg structure.

== Description ==

This plugin is an extension for the Polylang plugin for WordPress. It allows you to automatically translate content using the MyMemory API (translated.com).

* **One-Click Translation:** Easily translate posts and blocks.
* **Gutenberg Support:** Preserves the block structure during translation.
* **Flexible Limits:** Up to 500 characters/day for free, or up to 10000 characters/day with a registered email.

== Installation ==

1. Upload the `polylang-auto-translate` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Ensure Polylang is installed and active.
